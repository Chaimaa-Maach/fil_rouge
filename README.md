## Description

Ce projet a pour objectif d’analyser et d’anticiper le turnover des collaborateurs à partir de données RH inspirées de SAP SuccessFactors.
Il combine données internes simulées et données externes du marché afin de fournir des indicateurs décisionnels pour améliorer la rétention des talents.

---

## Objectifs

* Mesurer le turnover global et volontaire
* Identifier les populations à risque
* Comparer les salaires internes avec le marché (compa-ratio)
* Estimer le coût du turnover
* Construire un score de risque de départ

---

## Technologies utilisées

* Python (pandas, selenium, beautifulsoup)
* PostgreSQL
* SQL
* Power BI
* GitHub

---

## Données

Le projet s’appuie sur :

* Données internes simulées (collaborateurs, carrière, rémunération, performance, formation)
* Données externes (salaires du marché via web scraping)

---

## Pipeline du projet

1. Génération et nettoyage des données
2. Intégration dans PostgreSQL
3. Modélisation des données
4. Analyse et calcul des KPI
5. Visualisation via Power BI

---

## Résultats

* Tableaux de bord interactifs RH
* Analyse du turnover et de ses causes
* Identification des collaborateurs à risque
* Recommandations pour améliorer la rétention
